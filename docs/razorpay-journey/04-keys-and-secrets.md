## Rules that the folder follows

1. A raw key is never written as plain text.
2. A key is saved to the password manager at the prompt, before pressing Enter.
3. Encrypted copies are written with `ConvertFrom-SecureString` and decrypt only for the Windows account.
4. A list is uploaded only after each key has been checked against its own entry (`MATCHES`).
5. The clipboard is cleared with `Set-Clipboard " "` after a key is pasted.
